# Otel Web Sitesi – Vize Projesi

Bu proje, HTML ve CSS kullanılarak geliştirilmiş basit bir otel web sitesidir. 
Adıyaman üniversitesi dersinin vize ödevi kapsamında hazırlanmıştır.

## Projenin Amacı
Bu projenin amacı, temel web tasarım ve geliştirme becerilerini uygulamak ve
HTML ile CSS konularını pekiştirmektir.

## Sayfalar
- Anasayfa
- Hakkımızda
- Odalar
- Hizmetler
- Kampanyalar
- Rezervasyon
- İletişim

## Kullanılan Teknolojiler
- HTML5
- CSS3
